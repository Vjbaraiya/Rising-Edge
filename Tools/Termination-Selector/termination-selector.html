Every unterminated high-speed trace is an antenna for reflections

A PCB trace is a transmission line the moment the signal edge is fast compared to the round-trip propagation delay. If the load impedance does not match the line's characteristic impedance Z0, part of the incident wave reflects back toward the driver. That reflected energy adds to or subtracts from the original signal, causing overshoot, undershoot, ringing, and — at gigabit rates — closed eye diagrams and bit errors. Termination is how you dissipate or redirect that reflected energy so the receiver sees one clean edge instead of several.

Common mistake: Treating "termination" as a single fixed recipe. Series, parallel, Thevenin, AC and differential termination each solve a different combination of topology, power budget, and driver type — the right choice changes with the design, not just the data rate.

Concept explorer

Six termination strategies, one shared goal: make the load look like Z0 so the incident wave has nowhere reflective to go.

Series (source) termination

A resistor RS is placed close to the driver so that RS + Rdriver ≈ Z0. The driver now launches a half-amplitude step because the source looks matched to the line. The wave travels to the far end, and if the receiver is high-impedance (a single CMOS input), it reflects with ΓL ≈ +1 and doubles back up to full amplitude — which is exactly the logic level the receiver needs. The doubled wave travels back to the source, where the matched RS+Rdriver absorbs it (ΓS ≈ 0), so ringing stops after one round trip.

  • Best for point-to-point, single-receiver nets (SPI, GPIO, address/data to one device).
  • Draws current only while switching — near-zero static/DC power, ideal for battery designs.
  • Fails on multi-drop buses: only the far-end receiver sees the doubled step; middle taps see a half-step.
  • Placement matters — RS must sit within a few mm of the driver pin, not mid-trace.

Parallel (end) termination

A single resistor RP ≈ Z0 is placed at the receiver, to ground, to VDD, or to a mid-rail termination voltage VTT. The incident wave sees a matched load, so ΓL ≈ 0 and there is no reflection at all — the receiver sees one clean, full-amplitude edge on the first pass. The tradeoff is that RP now carries continuous DC current whenever the line is held at a static logic level, so power dissipation must be budgeted.

  • Preferred for multi-drop / always-terminated buses (RS-485, backplanes, wide parallel buses).
  • Static power P ≈ V2/RP — significant on wide buses with many terminated lines.
  • Terminating to VTT = VDD/2 halves the worst-case power versus terminating to ground.
  • Requires a clean, low-impedance VTT rail if not terminating straight to ground.

Thevenin (split) termination

Two resistors, R1 to VDD and R2 to ground, replace a single RP + VTT rail. Their Thevenin-equivalent resistance R1‖R2 is set to Z0, and their ratio sets the bias voltage the line idles at when nothing is driving. This is the classic answer when a board has no dedicated VTT supply but still needs matched termination — the two resistors synthesize the bias point from rails that already exist. The cost is continuous current flowing between VDD and ground through R1+R2 regardless of the data pattern.

  • Used when a separate VTT regulator is not available or not justified.
  • Continuous power P = VDD2/(R1+R2) — always on, even when idle.
  • Common on GTL/GTL+ buses, older memory buses, and some backplane designs.
  • Adds two components and two extra solder joints per line versus single-resistor parallel termination.

AC (RC) termination

A resistor R ≈ Z0 in series with a capacitor C, both to ground, terminate the line only at the frequencies that matter — the edge transitions. The capacitor blocks DC, so there is zero static power dissipation, but during a fast edge the capacitor briefly looks like a short and R provides the matched termination exactly when it is needed. The RC time constant must be long enough that C does not fully charge during a single bit period (or the termination effectively disappears for slow, low-frequency data) but short enough to settle before the next edge.

  • Rule of thumb: size τ = R·C to roughly 5–10× the bit period for reliable AC coupling.
  • Zero DC power — attractive for clock lines and buses that are otherwise power-constrained.
  • Ineffective for very low-speed or DC-heavy patterns — the cap simply charges up and the termination "disappears."
  • Used on some clock distribution nets and legacy GTL/backplane buses to cut static power.

Differential termination

A single resistor placed directly across the two legs of a differential pair, sized to the pair's differential impedance Zdiff (commonly ~90–100 Ω for LVDS/PCIe/USB, ~100–120 Ω for HDMI-class links). Because the two legs carry equal and opposite currents, a single resistor across them presents Zdiff to the differential mode while common-mode noise sees only half of it in each direction — differential termination does not directly control common-mode impedance, which needs separate consideration (or a resistor network to a common-mode point).

  • Used on LVDS, PCIe, USB SuperSpeed, HDMI/DisplayPort AC-coupled links.
  • Resistor tolerance matters — a ±1% part keeps residual mismatch reflections small; ±5% can measurably degrade eye height.
  • Many modern SerDes use on-die termination (ODT) instead of a discrete resistor.
  • AC-coupling capacitors in series with the pair interact with the termination network — verify high-pass corner is well below the lowest data content frequency.

There is no universally "best" termination — only the scheme that fits the topology, driver, and power budget in front of you. Use this quick filter, then confirm with the full interactive decision tree below.

Real engineering examples

The same physics, seven different industries.

Consumer / Memory

DDR3/DDR4/DDR5 memory bus

On-die termination (ODT) inside the DRAM and controller replaces discrete parallel resistors. JEDEC defines selectable ODT values (e.g. 40–240 Ω) so the same silicon adapts to single-rank or multi-rank topologies without board respins.

Industrial

RS-485 multi-drop bus

A 120 Ω resistor at each physical end of the twisted pair (never in the middle) matches the cable's differential impedance. TIA/EIA-485 explicitly calls out end-only termination — mid-bus termination creates a low-impedance load that starves every driver.

Networking / FPGA

LVDS clock & data links

A single 100 Ω resistor across each differential pair at the receiver matches Zdiff. FPGA I/O banks often integrate this as selectable on-die differential termination, removing the discrete part entirely.

Automotive

CAN / CAN-FD bus

120 Ω termination at both physical ends of the twisted pair, split into two 60 Ω resistors with a common-mode capacitor at the midpoint for EMI filtering — a differential-plus-common-mode hybrid of parallel termination.

Consumer

SPI flash / point-to-point GPIO

A single series resistor (often 22–33 Ω) near the driver is the default for short, single-receiver traces. It costs one component, no static power, and is "good enough" well below the trace's electrical length limit.

High-speed PCB

Clock trees / fan-out buffers

Series termination at each buffer output for short branches; parallel termination at the far end for longer branches feeding multiple loads. The choice depends on whether the branch length exceeds roughly 1/6 of the signal's rise-time electrical length.

Medical / Networking

PCIe / HDMI / high-speed SerDes

AC-coupled differential pairs with on-die (near-end and far-end) termination inside the SerDes. The coupling capacitors block DC bias differences between transmitter and receiver while the internal termination network absorbs the differential-mode reflection.

Design review: correct vs. incorrect layout

The same schematic net, two very different PCB outcomes.

Correct

Termination at the far end, short stub

  • Resistor placed at the physical end of the trace, in-line with the signal path.
  • Stub from the trace to the resistor pad kept < 1/10 of the rise-time electrical length.
  • Ground return directly beneath the resistor — low-inductance return path.
Incorrect

Termination mid-trace with a long stub

  • Resistor tapped off the middle of the trace instead of the true end.
  • Long stub to the resistor pad creates its own unterminated reflection point.
  • Signal still reflects from the real, still-open trace end past the tap.

Common mistakes

Mismatched resistor value

Root cause: Using a "standard" 100 Ω part without checking the actual Z0 from the stack-up.

Symptoms: Small but persistent ringing that doesn't fully disappear.

Impact: Reduced timing margin, intermittent failures at temperature/voltage corners.

Correct approach: Pull Z0 from the field-solver output for the actual stack-up, not a rule-of-thumb value.

Termination too far from the receiver

Root cause: Routing convenience — the resistor lands wherever there's board space.

Symptoms: A second, smaller reflection appears between the termination and the receiver pin.

Impact: Eye closure proportional to the stub's electrical length.

Correct approach: Keep the stub electrically short (< ~1/10 of the edge rise time) or move the resistor to the receiver footprint.

Parallel termination on a power-constrained rail

Root cause: Copy-pasting a desktop reference design onto a battery-powered product.

Symptoms: Unexpectedly high idle current draw traced back to terminated buses.

Impact: Shortened battery life, thermal margin eaten by resistors that are "always on."

Correct approach: Use series termination, AC termination, or dynamically switched termination for power-sensitive designs.

Forgetting AC-coupling cap interaction

Root cause: Treating the coupling capacitor and the termination network as independent design choices.

Symptoms: Low-frequency content (long runs of identical bits) gets attenuated or DC-wanders.

Impact: Baseline wander, bit errors on data patterns with long run lengths.

Correct approach: Verify the coupling network's high-pass corner sits well below the lowest frequency content in the encoded data (use 8b/10b or similar DC-balanced coding if needed).

Loose differential resistor tolerance

Root cause: Using a generic 5% resistor because "it's just a termination."

Symptoms: Small residual common-mode-to-differential conversion, marginal eye height at the compliance mask.

Impact: Intermittent compliance failures across manufacturing lots.

Correct approach: Use 1% (or tighter) tolerance resistors on differential termination for multi-gigabit links.

Ignoring driver output impedance

Root cause: Setting RS = Z0 directly, forgetting the driver already has non-zero output impedance.

Symptoms: Launch voltage lower than expected, extra reflection at the source.

Impact: Reduced noise margin, possible false triggering on noisy rails.

Correct approach: RS = Z0 − Rdriver, using the driver's actual datasheet output impedance at the operating voltage/temperature.

Engineering myths

Myth: "Always terminate every trace."

Why it exists: High-speed design guidelines repeat "match your impedance" so often that it gets over-generalized to every net.

Where it fails: Short traces (electrically short compared to the signal's rise time) never develop a meaningful reflection in the first place — adding termination there only adds cost, power and complexity.

Correct practice: Terminate when trace length exceeds roughly 1/6 of the electrical length of the rise time; otherwise, treat the net as lumped and skip it.

Myth: "Series termination eliminates the need for controlled impedance."

Why it exists: Series termination fixes the source-end mismatch, so it feels like the whole reflection problem is solved.

Where it fails: The trace itself still needs a known, controlled Z0 for the math to work — RS is calculated relative to that Z0. An uncontrolled trace has an unknown, often varying impedance that no fixed resistor can compensate for.

Correct practice: Controlled-impedance stack-up and routing are prerequisites for termination, not an alternative to it.

Myth: "Parallel termination is always better because it's a 'real' full-swing signal."

Why it exists: Parallel termination gives a clean, full-amplitude edge on the first pass, which looks superior on a scope.

Where it fails: That cleanliness costs continuous DC power on every terminated line — for point-to-point, power-sensitive designs, series termination gets the same clean edge at the receiver (via doubling) for a fraction of the power.

Correct practice: Match the scheme to the topology and power budget, not to which scope trace "looks nicer."

Myth: "Termination resistor value doesn't need to be precise — anything close to Z0 works."

Why it exists: A rough match does eliminate most of the reflection, so small errors are easy to overlook on a bench scope.

Where it fails: At multi-gigabit rates with tight timing budgets, even a 10% mismatch leaves measurable residual reflection that eats directly into eye margin.

Correct practice: Use tighter-tolerance resistors as data rate increases, and validate with TDR rather than assuming "close enough."

Termination engineering notes

Fundamentals, theory, equations, applications, best practices, failure modes, standards, design rules and troubleshooting — the reference layer behind every calculator output above.

What makes a trace a "transmission line"?

A trace behaves as a lumped node when its electrical length is short compared to the signal's rise time — the whole trace charges together and no meaningful reflection can build up. Once the trace's one-way propagation delay exceeds roughly 1/6 of the rise time, it must be treated as a distributed transmission line with a characteristic impedance Z0, and mismatches at either end start to matter. A common rule of thumb: if tPD > trise/6, terminate.

Characteristic impedance Z0 — what it physically is

Z0 is the ratio of voltage to current in a single traveling wave on the line, set entirely by the trace geometry and dielectric (per-unit-length inductance and capacitance): Z0 = √(L'/C'). It is not a lumped resistor and dissipates no power by itself — it only describes how the wave propagates. Typical single-ended PCB traces run 40–65 Ω; differential pairs run 80–120 Ω differential.

The reflection coefficient formula

Γ = (ZL − Z0) / (ZL + Z0), where ZL is the impedance the wave encounters (load, source, or any discontinuity). Γ = 0 means a perfect match, no reflection. Γ = +1 is an open circuit (full doubling). Γ = −1 is a short circuit (full inversion). The same formula applies at any impedance discontinuity — a via, a connector, a stub, or a component pad.

Why unterminated lines ring

An open, mismatched receiver reflects the incident wave almost entirely (ΓL ≈ +1). That reflected wave travels back to the driver, where the driver's own low output impedance is also mismatched to Z0, so it reflects again (ΓS typically negative). The wave bounces back and forth, losing a little energy each round trip to trace and dielectric losses, producing the decaying oscillation ("ringing") seen on a scope.

Series termination derivation

For zero reflection at the source, the total source-side resistance must equal Z0: RS + Rdriver = Z0, so RS = Z0 − Rdriver. The driver now launches Vlaunch = VDD × Z0/(Z0+RS+Rdriver) = VDD/2 into the line. At an open receiver, ΓL ≈ +1 doubles this back to VDD, giving a full logic swing exactly one round trip after the edge starts.

Parallel termination derivation

Setting RP = Z0 at the receiver makes ΓL = 0 — the wave is fully absorbed on arrival, no reflection travels back. The receiver sees a single, full-amplitude, unreflected transition. Static (DC) power when the line is held high: P = VOH2/RP if terminated to ground, or (VOH − VTT)2/RP if terminated to a VTT rail.

Thevenin termination derivation

R1 (to VDD) and R2 (to GND) must satisfy two simultaneous constraints: R1‖R2 = Z0 (matched AC impedance) and R2/(R1+R2) × VDD = Vbias (correct idle bias point). Solving: R2 = Z0×VDD/Vbias, R1 = Z0×VDD/(VDD−Vbias). Continuous current I = VDD/(R1+R2) flows regardless of the data pattern.

AC (RC) termination time-constant sizing

The capacitor must charge fast enough that R still looks matched during the edge, but slow enough that it doesn't fully charge (and stop absorbing) within one bit period. A workable starting point: τ = R·C ≈ 5–10 × the bit period Tbit. Too small a τ loses termination effectiveness on long runs of the same bit; too large a τ wastes board area and can interact with lower-frequency content in the data.

Differential impedance and single-resistor termination

For a symmetric differential pair, a single resistor of value Zdiff placed across the two legs presents the correct differential-mode termination because the two legs' currents are equal and opposite through the resistor. Zdiff is typically slightly less than 2× the single-ended Z0 of one trace due to coupling between the traces (odd-mode impedance × 2).

Common-mode vs. differential-mode termination

A single differential resistor controls only the differential-mode impedance; common-mode noise (both legs moving together, e.g. from ground bounce or EMI coupling) sees a different, usually much higher, impedance. Designs sensitive to common-mode noise sometimes add a center-tapped resistor pair (or a resistor network to a filtered common-mode point) in addition to the differential resistor.

Multiple reflections and the bounce (lattice) diagram

Engineers track successive reflections with a bounce diagram: plot position (x-axis) vs. time (y-axis), draw the incident wave as a diagonal line from source to load, and at each end multiply the arriving wave by that end's reflection coefficient to get the next diagonal. Summing all the arrivals at a given point over time gives the actual voltage waveform there — this is the basis of the live simulation above.

Rise time, electrical length, and when termination matters

Electrical length of the rise time = trise × vp (propagation velocity, ~1.5×108 m/s in FR-4 stripline). Traces electrically shorter than about 1/6 of this length can usually be left unterminated with negligible ringing; traces electrically longer need active termination management. A 1 ns rise time in FR-4 corresponds to roughly 25 mm of "safe" untreated trace length.

Driver output impedance and process/voltage/temperature variation

CMOS driver output impedance is not a fixed number — it varies with process corner, supply voltage, and temperature, often by ±30–50% across the full PVT range. Series termination calculated for a "typical" driver may under- or over-terminate at corners; some drivers include programmable output impedance (calibrated against an external precision resistor) specifically to control this variation, as used in DDR and high-speed SerDes I/O.

On-die termination (ODT) — how it works

Modern DRAM and SerDes I/O integrate a bank of switchable resistive legs inside the pad driver, digitally calibrated (often against an external precision reference resistor, "ZQ calibration" in DDR) to synthesize a target termination value without a discrete external resistor. This removes board-level component count and lets the same silicon adapt its termination to different loading conditions via register settings.

Series termination on multi-drop buses — why it fails

Series termination only creates a matched launch at the source; it relies on the doubling reflection at a single far-end open receiver to reach full amplitude. On a multi-drop bus, intermediate receivers see the wave before it has doubled — they get a half-amplitude step (plus whatever local reflections their own stub creates), which is often insufficient noise margin. Multi-drop buses generally need end (parallel) termination instead.

Stub length and via effects on termination

Every stub — a via, a component footprint tap, or a branch to a test point — is itself a small transmission-line discontinuity. An electrically long stub between the main trace and the termination resistor creates a secondary reflection point, effectively splitting the "one" reflection problem into two smaller ones. Keep stub length under roughly 1/10 of the rise-time electrical length, or move the resistor directly onto the trace end.

Power dissipation budgeting for terminated buses

On wide parallel buses (e.g. a 32-bit memory bus with parallel termination to VTT), total termination power is the sum across all terminated lines and can reach hundreds of milliwatts to multiple watts. This is a primary reason DDR moved to on-die termination with dynamic ODT (only enabled during active read/write bursts) rather than always-on discrete resistors.

VTT rail design considerations

A VTT termination rail must sink and source current (bidirectional, since data toggles both directions) and maintain low output impedance across the full current range without significant droop, or the termination benefit is lost. Dedicated VTT regulators are typically linear or specialized switching parts rated for bidirectional current, distinct from the main point-of-load converters on the board.

Failure mode: overshoot damaging the receiver

Doubling reflections that are supposed to land exactly at VDD can overshoot beyond it if the source isn't perfectly matched (residual reflection adds an extra bounce). Repeated or excessive overshoot beyond a device's absolute maximum input voltage rating can degrade or destroy the receiver's input ESD structure over time, even if the device appears to function correctly at first.

Failure mode: undershoot and false triggering

Ringing that dips the signal below the low-level noise margin (or above the high-level noise margin on the return swing) can cause a receiver to misinterpret a transition, especially on inputs without hysteresis (Schmitt-trigger) buffering. Adding series termination, slowing the edge rate, or switching to a Schmitt-trigger input are the typical mitigations.

Standards touchpoint: JEDEC and DDR ODT

JEDEC's DDR specifications (DDR3 JESD79-3, DDR4 JESD79-4, DDR5 JESD79-5) define the selectable on-die termination values and the calibration procedure (ZQ calibration against an external precision resistor) that both the memory controller and DRAM must support, ensuring interoperability across vendors.

Standards touchpoint: TIA/EIA-485 for RS-485

TIA/EIA-485-A specifies 120 Ω termination at each physical end of the bus (matching common twisted-pair cable impedance) and explicitly warns against termination at intermediate nodes. It also defines the driver's minimum differential output and the receiver's input sensitivity, which interact with the termination network's effect on signal swing.

Standards touchpoint: IPC-2141 and controlled impedance

IPC-2141 (and its successor IPC-2141A) provides the formulas and guidance for designing controlled-impedance PCB stack-ups — the prerequisite for any termination calculation to be meaningful. Field-solver tools implement these (and more exact 2D/3D field solutions) to compute Z0 from trace width, dielectric height, and copper thickness.

Verification: Time-Domain Reflectometry (TDR)

A TDR launches a fast step into the trace and measures the reflected voltage over time; the reflection coefficient at each point along the trace reveals the local impedance, letting engineers directly confirm Z0 and validate that a termination resistor is properly matched, correctly placed, and free of parasitic stub effects — the closest thing to "seeing" the transmission line behavior directly on the bench.

Verification: eye diagrams and reflection-induced closure

An eye diagram overlays many bit periods of a data signal; reflections shrink both the vertical eye height (amplitude margin) and horizontal eye width (timing margin) by adding residual energy from previous bits into the current bit period (a form of inter-symbol interference). Comparing eye diagrams with and without termination is a fast, visual way to confirm a termination scheme is working as intended.

Design rule: choosing between series and parallel by topology

Point-to-point, single receiver: default to series (lower power, simpler). Multi-drop / multiple receivers along one net: default to parallel or Thevenin at the true electrical end(s) of the bus. Daisy-chain with short branch stubs: series at each stage is often adequate if stub lengths stay short relative to rise time.

Design rule: resistor tolerance and package selection

Use tighter tolerance (1% or better) as data rate increases, since reflection error scales with resistor mismatch percentage. Prefer small, low-parasitic-inductance packages (0402/0201) for termination resistors on multi-GHz differential pairs, where a few hundred picohenries of package inductance can itself become a discontinuity.

Troubleshooting: ringing persists after adding termination

Check resistor placement (is it truly at the electrical end, or tapped mid-trace with a long stub?), verify the resistor value against the actual field-solved Z0 (not an assumed round number), and confirm the ground return path under the resistor is low-inductance. A termination resistor with a poor local ground connection can add as much parasitic inductance as it removes reflection.

Troubleshooting: unexpectedly high board power draw

Audit every parallel and Thevenin termination network for static current draw, especially on wide buses. A 32-line bus with 50 Ω parallel termination to a 1.65 V VTT can draw well over a watt continuously — often the single largest "hidden" power consumer on a digital board, easy to miss during initial power budgeting.

Design review checklist for termination

Confirm Z0 came from the actual field-solved stack-up; confirm topology (point-to-point vs. multi-drop) matches the chosen scheme; confirm resistor placement is at the true electrical end with a short stub; confirm power budget includes static termination current; confirm differential pairs use appropriately tight resistor tolerance; confirm AC-coupled links have a verified high-pass corner well below the data's lowest frequency content.
