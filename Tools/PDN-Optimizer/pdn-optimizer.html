Design for a flat, low-impedance rail

A PDN must supply transient current without exceeding the permitted ripple. Target impedance converts that requirement into a frequency-domain limit. A useful capacitor network spans bulk, mid-frequency, and high-frequency energy storage while controlling ESL-driven anti-resonance.

Common mistake: Adding many identical capacitors lowers ESR but does not extend bandwidth. Package, mounting inductance, and value diversity matter.

Example layout

Power supply (DC in → D1 → L1 → U1 buck regulator) feeds a shared VDD rail (gold) and GND rail (blue) running the length of the board. Bulk capacitance sits nearest the regulator; smaller, faster capacitors sit closest to the IC. Current leaves the regulator as a single wave that travels the rail left → right, charging each capacitor in turn — bulk cap first, smallest cap last — before finally supplying the device. Each capacitor's LED pulses blue as that wave arrives and flashes orange as it hands current onward, with the lead dot reversing direction to match. PDN design notes

The model treats each populated capacitor type as a parallel branch containing quantity-scaled series RLC impedance.

Target impedance

Ztarget = VDD × ripple fraction / transient current. The selected design margin lowers that ceiling before optimization, leaving room for model and layout uncertainty.

ESR, ESL, and self resonance

Below SRF, capacitance dominates. At SRF the branch approaches ESR. Above SRF, mounting and package inductance dominate. Smaller packages and shorter via loops extend useful bandwidth.

Parallel capacitors and anti-resonance

Mixed capacitor values widen bandwidth but can create high-Q peaks between resonances. Intermediate values, controlled ESR, and reduced connection inductance damp these peaks.

Placement strategy

Place the smallest, lowest-ESL capacitors closest to IC power pins with one power and one ground via at the pads. Use bulk capacitors near the VRM and distribute mid-value parts around the load.

Model limitations

This first-order model is for topology exploration. Validate the final layout with vendor S-parameters, DC-bias derating, VRM output impedance, package/plane models, and full-wave extraction where appropriate.
