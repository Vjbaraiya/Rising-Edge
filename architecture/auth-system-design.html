Authentication Flow Overview

1
RegistrationUser submits email + password → bcrypt hash → email verification token sent → record created with status PENDING_VERIFICATION
2
Email VerificationUser clicks link → token validated → status → ACTIVE → Basic subscription auto-provisioned
3
LoginCredentials validated → JWT access token (15 min) + refresh token (7 days, httpOnly cookie) → device fingerprint logged
4
Token RefreshAccess token expires → client calls /auth/refresh → refresh token rotated → new pair issued → old token blacklisted in Redis
5
AuthorizationEvery protected request: verify JWT → load user+subscription → check role → check subscription → check enrollment (content routes)
6
LogoutRefresh token deleted from DB + blacklisted in Redis → access token stateless-expires naturally

Token Strategy

Token Storage TTL Rotation Revocation
Access JWT Memory / Authorization header 15 minutes On every refresh Via Redis blacklist
Refresh Token httpOnly secure cookie + DB 7 days Every use (rotation) Delete from DB
Email Verify DB column 24 hours — Nulled on use
Password Reset DB column + hash 1 hour — Nulled on use

Security Controls

Input & Transport

  • Helmet.js — security headers
  • express-validator — all inputs
  • DOMPurify (client-side XSS)
  • Parameterized queries via Prisma (SQLi)
  • HTTPS-only, Secure + SameSite=Strict cookies
  • CORS whitelist

Rate Limiting

  • /auth/login → 5 req/15 min per IP
  • /auth/register → 3 req/hour per IP
  • /auth/forgot-password → 3 req/hour
  • Global API → 100 req/min per user
  • Implemented via express-rate-limit + Redis

Password Policy

  • Minimum 8 characters
  • At least 1 uppercase, 1 number, 1 symbol
  • bcrypt cost factor 12 (≈300ms hash time)
  • HaveIBeenPwned API check on registration

Audit & Monitoring

  • Every auth event → audit_logs table
  • Device + IP fingerprint on login
  • Suspicious login alert emails
  • Failed login counter → temp lockout at 5

Middleware Execution Order

# Middleware Applies To Purpose
1 helmet All X-Frame-Options, CSP, HSTS, etc.
2 cors All Whitelist allowed origins
3 rateLimiter All (custom on auth) Prevent brute force / DDoS
4 sanitizeInputs All POST/PUT Strip XSS payloads from body
5 validateInput Per-route Schema validation, type coercion
6 verifyToken Protected routes Decode + validate JWT
7 requireRole Role-gated routes RBAC enforcement
8 requireSubscription Feature-gated routes Plan level enforcement
9 requireEnrollment Course content routes Paid enrollment check
10 auditLogger Write operations Record action to audit_logs

Next.js Edge Middleware — middleware.ts
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';
import { jwtVerify } from 'jose';

const PUBLIC = ['/', '/trainings', '/about', '/login', '/register', '/forgot-password'];
const ADMIN_PATHS = ['/admin'];
const SUPERADMIN_PATHS = ['/system'];

export async function middleware(req: NextRequest) {
  const { pathname } = req.nextUrl;
  if (PUBLIC.some(p => pathname.startsWith(p))) return NextResponse.next();

  const token = req.cookies.get('accessToken')?.value;
  if (!token) return NextResponse.redirect(new URL('/login', req.url));

  try {
    const { payload } = await jwtVerify(token, new TextEncoder().encode(process.env.JWT_SECRET));
    const role = payload.role as string;

    if (SUPERADMIN_PATHS.some(p => pathname.startsWith(p)) && role !== 'SUPER_ADMIN')
      return NextResponse.redirect(new URL('/403', req.url));

    if (ADMIN_PATHS.some(p => pathname.startsWith(p)) && !['ADMIN','SUPER_ADMIN'].includes(role))
      return NextResponse.redirect(new URL('/403', req.url));

    return NextResponse.next();
  } catch {
    return NextResponse.redirect(new URL('/login', req.url));
  }
}

auth.middleware.js — Complete Middleware Suite

// src/middleware/auth.middleware.js
const jwt = require('jsonwebtoken');
const { PrismaClient } = require('@prisma/client');
const redis = require('../config/redis');

const prisma = new PrismaClient();
const PLAN_LEVEL = { BASIC: 1, ADVANCED: 2, PREMIUM: 3 };

/* ── verifyToken ─────────────────────────────────────────
   Validates JWT from Authorization header or cookie.
   Attaches req.user (with subscription) on success.
──────────────────────────────────────────────────────── */
async function verifyToken(req, res, next) {
  try {
    const token =
      req.cookies?.accessToken ||
      req.headers.authorization?.replace('Bearer ', '');

    if (!token) {
      return res.status(401).json({ success:false, error:'Access token required' });
    }

    // Check blacklist (logged-out tokens)
    const blacklisted = await redis.get(`bl:${token}`);
    if (blacklisted) {
      return res.status(401).json({ success:false, error:'Token has been revoked' });
    }

    const payload = jwt.verify(token, process.env.JWT_SECRET);

    const user = await prisma.user.findUnique({
      where: { id: payload.userId },
      include: { subscription: true },
    });

    if (!user) {
      return res.status(401).json({ success:false, error:'User not found' });
    }
    if (user.status === 'SUSPENDED') {
      return res.status(403).json({ success:false, error:'Account suspended' });
    }
    if (user.status === 'PENDING_VERIFICATION') {
      return res.status(403).json({ success:false, error:'Please verify your email' });
    }

    req.user = user;
    next();
  } catch (err) {
    if (err.name === 'TokenExpiredError') {
      return res.status(401).json({ success:false, error:'Token expired', code:'TOKEN_EXPIRED' });
    }
    return res.status(401).json({ success:false, error:'Invalid token' });
  }
}

/* ── requireRole ─────────────────────────────────────────
   Usage: requireRole('ADMIN', 'SUPER_ADMIN')
──────────────────────────────────────────────────────── */
function requireRole(...roles) {
  return (req, res, next) => {
    if (!req.user) return res.status(401).json({ success:false, error:'Unauthorized' });
    if (!roles.includes(req.user.role)) {
      return res.status(403).json({
        success: false,
        error: 'Insufficient permissions',
        required: roles,
        current: req.user.role,
      });
    }
    next();
  };
}

/* ── requireSubscription ─────────────────────────────────
   Usage: requireSubscription('ADVANCED', 'PREMIUM')
   User needs ANY of the listed plans (or higher tier).
──────────────────────────────────────────────────────── */
function requireSubscription(...requiredPlans) {
  const minLevel = Math.min(...requiredPlans.map(p => PLAN_LEVEL[p] || 99));

  return (req, res, next) => {
    if (!req.user) return res.status(401).json({ success:false, error:'Unauthorized' });

    const sub = req.user.subscription;
    const plan = sub?.plan || 'BASIC';
    const status = sub?.status || 'ACTIVE';

    if (status === 'EXPIRED' || status === 'CANCELLED') {
      return res.status(403).json({
        success: false,
        error: 'Subscription expired or cancelled',
        code: 'SUBSCRIPTION_EXPIRED',
      });
    }

    if ((PLAN_LEVEL[plan] || 0) < minLevel) {
      return res.status(403).json({
        success: false,
        error: 'Upgrade required to access this feature',
        code: 'UPGRADE_REQUIRED',
        currentPlan: plan,
        requiredPlans,
      });
    }

    next();
  };
}

/* ── requireEnrollment ───────────────────────────────────
   Checks user is enrolled in req.params.trainingId
──────────────────────────────────────────────────────── */
async function requireEnrollment(req, res, next) {
  try {
    const trainingId = req.params.trainingId || req.params.id;
    const userId = req.user.id;

    const enrollment = await prisma.enrollment.findUnique({
      where: { userId_trainingId: { userId, trainingId } },
    });

    if (!enrollment) {
      return res.status(403).json({
        success: false,
        error: 'You are not enrolled in this training',
        code: 'NOT_ENROLLED',
      });
    }

    if (enrollment.expiresAt && enrollment.expiresAt < new Date()) {
      return res.status(403).json({
        success: false,
        error: 'Your enrollment has expired',
        code: 'ENROLLMENT_EXPIRED',
      });
    }

    req.enrollment = enrollment;
    next();
  } catch (err) {
    next(err);
  }
}

module.exports = { verifyToken, requireRole, requireSubscription, requireEnrollment };

auth.controller.js — Register, Login, Refresh, Logout

// src/controllers/auth.controller.js
const bcrypt = require('bcrypt');
const jwt = require('jsonwebtoken');
const crypto = require('crypto');
const { PrismaClient } = require('@prisma/client');
const redis = require('../config/redis');
const emailService = require('../services/email.service');

const prisma = new PrismaClient();
const BCRYPT_ROUNDS = 12;
const ACCESS_TTL  = '15m';
const REFRESH_TTL = '7d';
const REFRESH_TTL_MS = 7 * 24 * 60 * 60 * 1000;

function generateTokens(userId, role) {
  const accessToken = jwt.sign(
    { userId, role },
    process.env.JWT_SECRET,
    { expiresIn: ACCESS_TTL }
  );
  const refreshToken = crypto.randomBytes(64).toString('hex');
  return { accessToken, refreshToken };
}

function setRefreshCookie(res, token) {
  res.cookie('refreshToken', token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'strict',
    maxAge: REFRESH_TTL_MS,
    path: '/api/auth',
  });
}

/* ── REGISTER ──────────────────────────────────────────── */
exports.register = async (req, res) => {
  const { fullName, email, password } = req.body;

  const existing = await prisma.user.findUnique({ where: { email } });
  if (existing) {
    return res.status(409).json({ success:false, error:'Email already registered' });
  }

  const passwordHash = await bcrypt.hash(password, BCRYPT_ROUNDS);
  const emailVerifyToken = crypto.randomBytes(32).toString('hex');

  const user = await prisma.user.create({
    data: {
      fullName, email, passwordHash,
      emailVerifyToken,
      role: 'USER',
      status: 'PENDING_VERIFICATION',
      subscription: { create: { plan:'BASIC', status:'ACTIVE' } },
    },
  });

  await emailService.sendVerification(email, emailVerifyToken);

  res.status(201).json({
    success: true,
    message: 'Registration successful. Please verify your email.',
  });
};

/* ── LOGIN ─────────────────────────────────────────────── */
exports.login = async (req, res) => {
  const { email, password } = req.body;
  const ip = req.ip;
  const ua = req.headers['user-agent'] || '';

  const user = await prisma.user.findUnique({
    where: { email },
    include: { subscription: true },
  });

  if (!user || !(await bcrypt.compare(password, user.passwordHash))) {
    if (user) {
      await prisma.loginHistory.create({
        data: { userId: user.id, ipAddress: ip, userAgent: ua, success: false },
      });
    }
    return res.status(401).json({ success:false, error:'Invalid email or password' });
  }

  if (!user.emailVerified) {
    return res.status(401).json({ success:false, error:'Please verify your email first' });
  }
  if (user.status !== 'ACTIVE') {
    return res.status(403).json({ success:false, error:'Account is suspended. Contact support.' });
  }

  const { accessToken, refreshToken } = generateTokens(user.id, user.role);

  await prisma.refreshToken.create({
    data: {
      userId: user.id, token: refreshToken,
      ipAddress: ip, userAgent: ua,
      expiresAt: new Date(Date.now() + REFRESH_TTL_MS),
    },
  });

  await prisma.loginHistory.create({
    data: { userId: user.id, ipAddress: ip, userAgent: ua, success: true },
  });

  setRefreshCookie(res, refreshToken);

  res.json({
    success: true,
    accessToken,
    user: {
      id: user.id, fullName: user.fullName, email: user.email,
      role: user.role,
      plan: user.subscription?.plan || 'BASIC',
      avatarUrl: user.avatarUrl,
    },
  });
};

/* ── REFRESH TOKEN ─────────────────────────────────────── */
exports.refresh = async (req, res) => {
  const token = req.cookies?.refreshToken;
  if (!token) return res.status(401).json({ success:false, error:'No refresh token' });

  // Check blacklist
  const blacklisted = await redis.get(`bl_rt:${token}`);
  if (blacklisted) {
    // Possible token replay — revoke all user tokens
    const record = await prisma.refreshToken.findUnique({ where: { token } });
    if (record) await prisma.refreshToken.deleteMany({ where: { userId: record.userId } });
    return res.status(401).json({ success:false, error:'Security event. Please log in again.' });
  }

  const record = await prisma.refreshToken.findUnique({
    where: { token },
    include: { user: { include: { subscription: true } } },
  });

  if (!record || record.expiresAt < new Date()) {
    return res.status(401).json({ success:false, error:'Session expired. Please log in again.' });
  }

  const user = record.user;
  const { accessToken, refreshToken: newRefresh } = generateTokens(user.id, user.role);

  // Rotate: delete old, create new
  await prisma.refreshToken.delete({ where: { token } });
  await prisma.refreshToken.create({
    data: {
      userId: user.id, token: newRefresh,
      ipAddress: req.ip, userAgent: req.headers['user-agent'] || '',
      expiresAt: new Date(Date.now() + REFRESH_TTL_MS),
    },
  });

  // Blacklist old refresh token
  await redis.setEx(`bl_rt:${token}`, 7 * 24 * 60 * 60, '1');

  setRefreshCookie(res, newRefresh);
  res.json({ success: true, accessToken });
};

/* ── LOGOUT ────────────────────────────────────────────── */
exports.logout = async (req, res) => {
  const token = req.cookies?.refreshToken;
  if (token) {
    await prisma.refreshToken.deleteMany({ where: { token } });
    await redis.setEx(`bl_rt:${token}`, 7 * 24 * 60 * 60, '1');
    res.clearCookie('refreshToken', { path: '/api/auth' });
  }
  res.json({ success: true, message: 'Logged out successfully' });
};

/* ── FORGOT PASSWORD ───────────────────────────────────── */
exports.forgotPassword = async (req, res) => {
  const { email } = req.body;
  const user = await prisma.user.findUnique({ where: { email } });

  // Always return 200 to prevent email enumeration
  if (!user) return res.json({ success:true, message:'If that email exists, a reset link has been sent.' });

  const token = crypto.randomBytes(32).toString('hex');
  const expiry = new Date(Date.now() + 60 * 60 * 1000); // 1 hour

  await prisma.user.update({
    where: { id: user.id },
    data: { passwordResetToken: token, passwordResetExpiry: expiry },
  });

  await emailService.sendPasswordReset(email, token);
  res.json({ success:true, message:'If that email exists, a reset link has been sent.' });
};

/* ── RESET PASSWORD ────────────────────────────────────── */
exports.resetPassword = async (req, res) => {
  const { token, newPassword } = req.body;

  const user = await prisma.user.findFirst({
    where: {
      passwordResetToken: token,
      passwordResetExpiry: { gt: new Date() },
    },
  });

  if (!user) {
    return res.status(400).json({ success:false, error:'Invalid or expired reset token' });
  }

  const passwordHash = await bcrypt.hash(newPassword, BCRYPT_ROUNDS);

  await prisma.user.update({
    where: { id: user.id },
    data: {
      passwordHash,
      passwordResetToken: null,
      passwordResetExpiry: null,
    },
  });

  // Revoke all refresh tokens (force re-login on all devices)
  await prisma.refreshToken.deleteMany({ where: { userId: user.id } });

  res.json({ success:true, message:'Password reset successfully. Please log in.' });
};

// src/services/subscription.service.js
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();

const PLAN_LEVEL = { BASIC: 1, ADVANCED: 2, PREMIUM: 3 };

const PLAN_FEATURES = {
  BASIC: {
    maxDownloads: 5,
    aiUsageLimit: 10,
    canAccessPaidTrainings: false,
    canUsePCBTool: false,
    canUseAIAssistant: false,
    canDownloadCertificates: false,
  },
  ADVANCED: {
    maxDownloads: 50,
    aiUsageLimit: 100,
    canAccessPaidTrainings: true,
    canUsePCBTool: false,
    canUseAIAssistant: false,
    canDownloadCertificates: true,
  },
  PREMIUM: {
    maxDownloads: Infinity,
    aiUsageLimit: Infinity,
    canAccessPaidTrainings: true,
    canUsePCBTool: true,
    canUseAIAssistant: true,
    canDownloadCertificates: true,
  },
};

/**
 * Returns the features available for a given plan (or the user's current plan).
 */
function getPlanFeatures(plan) {
  return PLAN_FEATURES[plan] || PLAN_FEATURES.BASIC;
}

/**
 * Returns true if userPlan satisfies the minimum required plan.
 */
function hasAccess(userPlan, requiredPlan) {
  return (PLAN_LEVEL[userPlan] || 0) >= (PLAN_LEVEL[requiredPlan] || 0);
}

/**
 * Upgrades a user's subscription after successful payment.
 */
async function upgradeSubscription(userId, newPlan, paymentId) {
  return prisma.userSubscription.upsert({
    where: { userId },
    update: {
      plan: newPlan,
      status: 'ACTIVE',
      startDate: new Date(),
      endDate: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000), // 30 days
      paymentId,
    },
    create: {
      userId,
      plan: newPlan,
      status: 'ACTIVE',
      paymentId,
      endDate: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000),
    },
  });
}

/**
 * Checks and expires overdue subscriptions (run as cron job).
 */
async function expireSubscriptions() {
  const expired = await prisma.userSubscription.updateMany({
    where: {
      status: 'ACTIVE',
      endDate: { lt: new Date() },
      plan: { not: 'BASIC' }, // BASIC never expires
    },
    data: { status: 'EXPIRED' },
  });
  return expired.count;
}

module.exports = { getPlanFeatures, hasAccess, upgradeSubscription, expireSubscriptions };

Frontend — AuthContext + useAuth Hook

// lib/AuthContext.tsx
'use client';
import { createContext, useContext, useState, useEffect, useCallback, ReactNode } from 'react';
import { api } from './api';

interface User {
  id: string; fullName: string; email: string;
  role: 'USER' | 'ADMIN' | 'SUPER_ADMIN';
  plan: 'BASIC' | 'ADVANCED' | 'PREMIUM';
  avatarUrl?: string;
}

interface AuthCtx {
  user: User | null;
  loading: boolean;
  login: (email: string, password: string) => Promise<void>;
  logout: () => Promise<void>;
  hasRole: (...roles: string[]) => boolean;
  hasPlan: (...plans: string[]) => boolean;
}

const PLAN_LEVEL: Record<string, number> = { BASIC:1, ADVANCED:2, PREMIUM:3 };
const AuthContext = createContext<AuthCtx>({} as AuthCtx);

export function AuthProvider({ children }: { children: ReactNode }) {
  const [user, setUser] = useState<User | null>(null);
  const [loading, setLoading] = useState(true);

  // On mount, try to load the session
  useEffect(() => {
    api.get('/users/me')
      .then(r => setUser(r.data.user))
      .catch(() => setUser(null))
      .finally(() => setLoading(false));
  }, []);

  const login = async (email: string, password: string) => {
    const { data } = await api.post('/auth/login', { email, password });
    api.defaults.headers.common['Authorization'] = `Bearer ${data.accessToken}`;
    setUser(data.user);
  };

  const logout = async () => {
    await api.post('/auth/logout');
    delete api.defaults.headers.common['Authorization'];
    setUser(null);
  };

  const hasRole = useCallback((...roles: string[]) =>
    !!user && roles.includes(user.role), [user]);

  const hasPlan = useCallback((...plans: string[]) => {
    if (!user) return false;
    const minRequired = Math.min(...plans.map(p => PLAN_LEVEL[p] || 99));
    return (PLAN_LEVEL[user.plan] || 0) >= minRequired;
  }, [user]);

  return (
    <AuthContext.Provider value={{ user, loading, login, logout, hasRole, hasPlan }}>
      {children}
    </AuthContext.Provider>
  );
}

export const useAuth = () => useContext(AuthContext);

Frontend — Axios Instance with Token Refresh Interceptor

// lib/api.ts
import axios from 'axios';

export const api = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL || 'http://localhost:4000/api',
  withCredentials: true, // send httpOnly cookies
});

let isRefreshing = false;
let queue: Array<(token: string) => void> = [];

api.interceptors.response.use(
  r => r,
  async err => {
    const original = err.config;

    if (err.response?.status === 401 &&
        err.response?.data?.code === 'TOKEN_EXPIRED' &&
        !original._retry) {
      original._retry = true;

      if (isRefreshing) {
        // Queue other requests while refreshing
        return new Promise(resolve => {
          queue.push(token => {
            original.headers['Authorization'] = `Bearer ${token}`;
            resolve(api(original));
          });
        });
      }

      isRefreshing = true;
      try {
        const { data } = await axios.post(
          `${api.defaults.baseURL}/auth/refresh`,
          {}, { withCredentials: true }
        );
        const { accessToken } = data;
        api.defaults.headers.common['Authorization'] = `Bearer ${accessToken}`;
        queue.forEach(cb => cb(accessToken));
        queue = [];
        original.headers['Authorization'] = `Bearer ${accessToken}`;
        return api(original);
      } catch {
        window.location.href = '/login';
        return Promise.reject(err);
      } finally {
        isRefreshing = false;
      }
    }

    return Promise.reject(err);
  }
);
